# Python Expense Tracker

## Project Overview
A simple, menu-driven expense tracking application built using Python.

The application allows users to record expenses, view all recorded expenses, and calculate total spending by category.

## Features
- Add an expense.
- View all expenses.
- Calculate total spending by category.
- Quit the application.

## Technologies Used
- Python

## Python Concepts Practiced
- Variables and data types
- Lists and dictionaries
- If, elif and else statements
- For and while loops
- User input
- Dictionary methods

## Current Limitations
Expenses are stored in memory and are not permanently saved after the program exits.
