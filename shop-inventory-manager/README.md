# Shop Inventory Manager

## Project Overview
This is a beginner Python project that manages inventory for a fictional small shop. It displays product quantities, identifies products with low stock, and calculates the total number of units in stock.

## Project Objectives
- Display products and their quantities.
- Identify products that need restocking.
- Show the stock status of each product.
- Calculate the total units in inventory.

## Tools Used
- Python
- Google Colab
- GitHub

## Python Concepts Practiced
- Dictionaries
- Variables
- `print()`
- `for` loops
- `if` and `else` statements
- `sum()`
- F-strings

## Stock Rule
A product is marked as low stock when its quantity is fewer than 5 units.

## Sample Inventory
| Product | Quantity |
|---|---:|
| Rice | 10 |
| Sugar | 4 |
| Cooking Oil | 2 |
| Beans | 8 |
| Flour | 3 |

## Result
The program calculates a total of 27 units in stock and identifies three products that need restocking.
